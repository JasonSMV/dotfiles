# Git Conventions

## Commit Format

```
[TICKET-ID] <type>: <emoji> <description>
```

- Prefix ticket when provided: `KT-11202 feat: ✨ add trip filter`
- Omit ticket when none: `fix: 🐛 handle null response`
- Description: short, imperative, lowercase after emoji
- NEVER add "Co-Authored-By" or AI attribution

## Types

| Type | Emoji |
|------|-------|
| feat | ✨ |
| fix | 🐛 |
| refactor | 🔨 |
| chore | 🧹 |
| style | 💅 |
| docs | 📜 |
| ci | 📦 |
| deploy | 🚀 |
